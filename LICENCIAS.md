# Licencias y alcance

El material original de este proyecto se ofrece bajo las siguientes licencias. Los titulares conservan sus derechos; no se exige cesión exclusiva a la iniciativa promotora. Los avisos específicos de terceros prevalecen para su propio material.

| Material | Licencia |
| --- | --- |
| Código del prototipo (`prototipo/*.mjs`, `prototipo/*.css`, `prototipo/*.html`), `verificar.py` y código propio de servicio que no indique otra licencia | [AGPL-3.0-or-later](LICENSE) |
| Documentación original (`*.md`, incluida la documentación dentro de directorios) | [CC-BY-SA-4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Captura ficticia `prototipo/comunidad-verificada.png` | [CC-BY-SA-4.0](LICENSES/CC-BY-SA-4.0.txt) |
| SDK o bibliotecas independientes de integración que se incorporen con aviso expreso | [Apache-2.0](LICENSES/Apache-2.0.txt) |

Todavía no existe un SDK ni una biblioteca independiente de integración. Incluir el texto Apache-2.0 no cambia la licencia AGPL del prototipo. Toda extracción futura deberá delimitar su alcance y comprobar derechos y compatibilidad; el nombre de un directorio no concede una excepción automática.

Los archivos fuente incluyen identificadores SPDX. Los archivos de configuración originales `.gitignore` y `.editorconfig` se ofrecen también bajo AGPL-3.0-or-later. La documentación incluye la licencia en sus metadatos. El archivo junto a la imagen declara la licencia de ese recurso. El texto AGPL completo figura en `LICENSE`, con copia en `LICENSES/AGPL-3.0-or-later.txt`.

## Exclusiones

Los textos canónicos de las licencias se reproducen sin alteraciones bajo sus propios avisos. Sus versiones inglesas se mantienen deliberadamente en el idioma original. Los enlaces y las referencias bibliográficas no relicencian las obras enlazadas. Los nombres y marcas de productos ajenos siguen sujetos a sus derechos correspondientes.

Esta concesión se refiere a código y documentación originales del proyecto. No concede derechos sobre datos personales ni sobre contenidos de futuros participantes. Tampoco acredita cumplimiento de contratos de servicio, seguridad, privacidad o disponibilidad de una red operativa.

## Contribuciones

Salvo acuerdo explícito compatible para un caso concreto, una aportación incorporada debe ofrecerse bajo la misma licencia del material al que contribuye. La persona que aporta conserva su autoría y debe disponer de derechos suficientes para hacerlo. No incorporar código o documentación de terceros únicamente porque sea accesible en Internet.

La reciprocidad de infraestructura se estudia como política de servicios. No se añade a estas licencias como restricción comercial, canon, condición de uso del código o prohibición de clientes compatibles.
